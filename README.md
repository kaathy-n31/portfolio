# Katheri Negrete | Portfolio

Portafolio base creado con Next.js, React y TypeScript.

## Comandos

```bash
npm run dev
npm run build
npm run typecheck
```

## Arquitectura

- `app/`: rutas, layout global y estilos base.
- `components/layout/`: header y footer.
- `components/sections/`: secciones principales del portafolio.
- `components/ui/`: componentes reutilizables pequenos.
- `data/portfolio.ts`: informacion editable del perfil, proyectos, habilidades y experiencia.
- `public/`: assets estaticos, incluido el placeholder de perfil.

## Siguiente contenido a reemplazar

Actualiza primero `data/portfolio.ts` con informacion real. Despues puedes agregar imagenes en `public/` y ampliar las tarjetas de proyecto con enlaces, metricas y casos de estudio.
